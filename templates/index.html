📖 數據分析師的「SQL + Python 4 步思考與選圖 SOP」

第 1 步：基礎體檢與看主角（目標變數 Y）

🐍 Python 寫法： df.isnull().sum()、df.duplicated().sum()、df['目標欄位'].value_counts()

💻 SQL 寫法： SELECT 目標欄位, COUNT(*) FROM 表名 GROUP BY 目標欄位

第 2 步：篩選重點配角（全表掃描 X 對 Y）

🐍 Python 寫法： df.corr()['目標欄位'].sort_values() 或 sns.heatmap(df.corr())

💻 SQL 寫法： SELECT 目標欄位, AVG(欄位A), AVG(欄位B) FROM 表名 GROUP BY 目標欄位

第 3 步：單挑重點特徵找「黃金分界線（Threshold）」

🐍 Python 寫法： sns.boxplot(data=df, x='目標欄位', y='重點特徵') 看箱子分界。

💻 SQL 寫法： 用 CASE WHEN 或 ROUND() 切區間，搭配 雙軸折線長條圖 找轉折點。

第 4 步：規則驗證與機器學習建模

🐍 Python 寫法： 用 RandomForestClassifier / RandomForestRegressor 抓出特徵重要性排行。

💻 SQL 寫法： 用 WITH (CTE) 計算風險燈號總分與單一戰犯歸因。

1️⃣ 左右橫向關聯（SQL JOIN / Python pd.merge）— 適合不同結構但有共同編號的表
