# Manufacturing defects demo data

Original dataset: https://www.kaggle.com/datasets/rabieelkharoua/predicting-manufacturing-defects-dataset

The Kaggle API lists the source dataset under **CC BY 4.0**. The original `manufacturing_defect_dataset.csv` is attributed to Rabie El Kharoua.

`production_orders_erp.csv` is derived from the original CSV. Its `OrderID`, `SupplierID`, and `MachineID` columns were generated for this teaching demo. `supplier_master.csv` and `machine_master.csv` are generated companion tables, not real ERP records from the Kaggle dataset.
