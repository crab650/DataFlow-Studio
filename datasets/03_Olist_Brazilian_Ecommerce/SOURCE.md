# Olist Brazilian E-Commerce Public Dataset

Official source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

License reported by Kaggle API: CC BY-NC-SA 4.0.

The large `olist_geolocation_dataset.csv` is deliberately omitted from this beginner SQL project. The eight included files preserve the core order, customer, item, payment, review, product, seller, and category relationships.
